# Third-party code

These files are from [thqby/ahk2_lib](https://github.com/thqby/ahk2_lib), unchanged, at commit `06aed7a1c42f754dfcb67962d055311a480d0848` (2026-05-20). They're MIT-licensed; see [LICENSE](LICENSE).

| File | What it is |
|---|---|
| `WebView2/WebView2.ahk` | AutoHotkey v2 bindings for Microsoft Edge WebView2 (v2.0.5) |
| `WebView2/64bit/WebView2Loader.dll` | Microsoft's WebView2 loader 1.0.3595.46, signed by Microsoft Corporation |
| `Promise.ahk`, `ComVar.ahk` | Helpers that `WebView2.ahk` includes |

`glint-panel.ahk` uses them to show `panel/glint-panel.html` in a frameless window. The WebView2 runtime itself comes with Windows 11.
